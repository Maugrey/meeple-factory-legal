About these pages

Here you can find the privacy policy, terms of use and support information for Meeple Factory, a mobile meeple-sorting game. The first version is being prepared for Android and Google Play, for a mixed audience including children and adults.

The game rules described here explain the intended behaviour of v1.0. They do not certify that every feature is already available in a test version. The final documents will match the distributed build before any distribution beyond the internal testing track.

This website and the game

This website is informational only: the publisher adds no sales, advertising, analytics, application cookies, forms or accounts. GitHub Pages hosts it and retains technical security logs, including visitors’ IP addresses. The game plans to use separate services, described in the privacy policy.

Reading these pages or using the game does not give consent to detailed analytics or personalised advertising. The choices will be presented separately in the game.
