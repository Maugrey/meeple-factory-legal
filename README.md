# Documents légaux publics — Meeple Factory

Ce dépôt publie le socle légal public de Meeple Factory via GitHub Pages. Il ne
contient ni le code du jeu, ni données de joueurs, ni identifiants de production.

Les pages sont volontairement statiques : aucun tracker, cookie applicatif,
formulaire ou compte n'est utilisé.

## URLs stables

- `/` — accueil légal ;
- `/privacy/` — politique de confidentialité ;
- `/terms/` — conditions d'utilisation ;
- `/support/` — support et contact ;
- `/contracts/` — contrats d'intégration provisoires.

Chaque page est disponible en français (racine) et en anglais sous `/en/`.

## Statut des textes

Version préparatoire du 6 septembre 2026. Les éléments explicitement marqués
« à confirmer » seront revus avant la publication du jeu, après le gel des SDK
et des réglages de production. Ce contenu ne constitue pas un avis juridique.
